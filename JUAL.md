# 💰 JUAL.md — Panduan Jual Source Code RASA

> Source code bagus yang nggak dipromosiin = nggak laku. Ikutin playbook ini.

## 1. Siapin Produk (1 Hari)

- [ ] Ganti nama demo secukupnya (biar berasa "milikmu"): `appName`, warna, icon.
- [ ] Build APK demo via GitHub Actions → dapat link Artifacts.
- [ ] Rekam video demo 60–90 detik (alurnya di bawah).
- [ ] Tulis `README.pdf` versi cantik (export dari README.md + screenshot).
- [ ] Tentuin harga & lisensi (lihat tabel).

## 2. Harga Patokan 2026 🇮🇩

| Paket | Harga | Isi |
|---|---|---|
| Personal | Rp149–199rb | Source + APK demo + setup via PDF |
| Premium | Rp349–499rb ⭐ | + video setup 15 mnt + Figma + grup support 30 hari |
| Extended / Jasa | Rp1,5–5jt | + ganti nama/warna + publish Play Store + konsultasi |

⭐ Paling laku biasanya paket Premium. Pasang di **Lynk.id / Mayar.id** (pembayaran QRIS otomatis).

Marketplace global: **Codecanyon** ($49–69, review ketat: butuh dokumentasi Inggris) atau **Gumroad** ($29–49, bebas).

## 3. Lisensi (Tulis di Halaman Jualan)

- **Regular:** 1 projek/app. Dilarang jual-ulang source mentah.
- **Extended:** unlimited projek + boleh dipakai untuk klien (jasa).
- Dilarang upload ke GitHub publik / forum bajakan. Kasih watermark: tiap pembeli dapat kode lisensi unik di file `LICENSE-{kode}.txt` (biar ketahuan kalau bocor).

## 4. Script Video Demo 60 Detik (TikTok/Reels/Shorts)

```
0-5s   HOOK: "Gua bikin aplikasi curhat anonim + AI dalam 30 hari 😱"
5-20s  Onboarding → pilih nama samaran lucu → pilih mood 😔
20-35s Tulis curhat → KIRIM → AI langsung bales dalam 3 detik ✨ (zoom!)
35-50s Scroll feed → tekan Peluk 🫂 → buka Biliar Chat → match random
50-60s CTA: "Source code + tutorial ada di bio. Komen MAU biar gua DM!"
```

Posting jam 19.00–21.00, hashtag: #flutter #sourcecode #ngoding #aplikasi #ai #sideproject

## 5. Demo yang Bikin Orang Transfer

1. **APK langsung coba** (Google Drive / Appetize link) — orang Indonesia males baca, maunya pencet.
2. **Screenshot rapi:** 5 layar (onboarding, feed, detail+AI, AI chat, profil) dalam mockup HP.
3. **Bukti build ijo:** screenshot GitHub Actions ✅ — ini naikin trust developer.
4. **Garansi 7 hari:** "refund kalau source nggak bisa di-build ngikutin SETUP.md" (berani karena demo mode).

## 6. Upsell Biar Cuan Maksimal

- Jasa reskin (ganti nama/warna/icon): 300–800rb
- Jasa setup Firebase + publish Play Store: 500rb–1,5jt
- Kelas "bedah source code RASA" (2 jam, Zoom): 99rb/orang
- Template turunan: RASA versi Komunitas Sekolah / Kantor / Fanbase (reskin + jual lagi!)

## 7. Anti-Bocor Seadanya

- Jangan pernah upload full source ke GitHub publik dengan harga. Bikin repo publik cuma berisi README + screenshot + link beli (private repo full dikirim setelah bayar).
- Tiap pembeli: ganti 1 string unik (`buyerCode`) biar ketahuan sumber bocoran.
- Daftarkan HKI (hak cipta program komputer) kalau sudah laku > 10jt — murah, online di e-hakcipta.dgip.go.id.
